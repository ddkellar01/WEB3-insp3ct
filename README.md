# WEB3-insp3ct

A cross-platform developer suite for inspecting DOM trees, browser extensions, and Web3 JSON-RPC payloads.

## Features
- **Browser Extension**: Built for Manifest V3 with dedicated DevTools panels.
- **Mobile Companion**: Built with Flutter for iOS and Android APK builds.
- **CI/CD Pipeline**: GitHub Actions for automated cross-platform releases.

## Quick Start
```bash
npm install
npm run dev
